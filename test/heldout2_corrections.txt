held-out 2 정답지 정정 기록 (2026-10-29 심야)

처음 정답지는 파이썬이 원본 CSV 에서 계산했지만, 건강관련통계정보(데이터 1325)의 0 을 ‘값 0’으로 읽은 것이 잘못이었다.
이 표의 비고 열에는 ‘의료기관수 / 의료기관 종사자수 미조사’, ‘자살률 / 스트레스 인지율 미조사’ 같은 말이 있고, 해당 칸이 0 으로 적혀 있다(조사하지 않은 칸을 0 으로 채움).
앱도 같은 실수를 했기 때문에 세 문항이 ‘통과’로 보였다.
  - 2020년 제주 자살률은 얼마야?          → 0 이라고 답함(통과로 오판). 정답: 값 없음(거절)
  - 2021년 제주 의료기관 종사자수는?      → 0 이라고 답함(통과로 오판). 정답: 값 없음(거절)
  - 제주 비만율이 가장 낮았던 해는?       → 2019년(0)이라고 답함(통과로 오판). 정답: 0 제외 후 최솟값(2010년 26.5, 2011년도 같은 값)
첫 실행 기록(heldout2_first_run.txt)의 14/21 은 정정 전 정답지 기준이다. 정정한 정답지로 같은 첫 실행 결과를 다시 채점하면 11/21 이다.
조치: 앱이 ‘비고에 미조사류가 적힌 표의 0 은 값으로 쓰지 않는다’(agent.js hasMissingNote, 검증기 verify.js 에도 별도 구현)로 바꾸고, 부정 시험에 두 문항을 추가했다.
